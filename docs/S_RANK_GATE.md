# S-Rank Gate

## Status: LOCKED — MVP in progress

**XP alone cannot unlock S-Rank.**

To unlock S-Rank, Prat must complete and ship the iOS Focus Remind App MVP built in Swift/SwiftUI.

## Unlock Checklist

| # | Condition | Status |
|---|-----------|--------|
| 1 | iOS Focus Remind App MVP created in Swift/SwiftUI | Pending |
| 2 | App can create a focus quest with title, duration, reminder | Pending |
| 3 | App can trigger local notifications (system-alert style) | Pending |
| 4 | App can run a focus session with countdown timer | Pending |
| 5 | App can mark a session complete and award XP | Pending |
| 6 | App shows S-Rank Gate progress screen | Pending |
| 7 | Code committed to repo | Pending |
| 8 | Demo recorded or screenshots captured | Pending |

## Gate Rules
- All 8 conditions must be met
- No shortcuts — cloud sync, fancy UI, or extra features do NOT count toward the gate
- The app must be functional and runnable in Xcode
- Prat must personally run and demo the app

## Visual Rank Feedback (Gemini Recommendation)
When implementing the iOS app, the Home/System Panel should include:
- A **"Glitch" effect** or **Deep Purple/Blue color gradient** that intensifies as the user nears the S-Rank Gate completion
- This provides a psychological "Creative Growth" feedback loop
- The visual should feel like the system is "awakening" as more conditions are met
- Use SwiftUI animations — subtle at 0-2 conditions, dramatic at 6-7 conditions

## Notification Copy Style
Notifications should feel like system alerts, not generic reminders:
- `"SYSTEM ALERT: Focus Quest Available — Return to the mission."`
- `"EMERGENCY QUEST: Your focus session expires in 10 minutes."`
- `"GATE WARNING: S-Rank remains locked. Complete your quest."`

## What Happens After S-Rank
Once S-Rank is unlocked:
- New quest tier unlocks (Shadow Monarch questline)
- Shadow Fusion quest becomes available
- iOS app becomes the primary focus tracking tool
- Discord bot syncs with iOS app (future sprint)
